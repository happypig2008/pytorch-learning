## 一、 创作背景与想法
在完成任务三后，虽然手写的 CNN 模型在测试集上达到了 98.84% 的准确率，但它只能通过命令行（黑框框）输出冰冷的数字，缺乏直观的交互体验。
为了让 AI 算法真正“落地”，我决定结合前几天学到的知识，开发一个轻量级的 Web 应用。用户可以直接在网页上用鼠标画板写出 0-9 的数字。

## 二、 开发工具与软硬件环境
- **操作系统**：Windows (新电脑)
- **开发环境**：Miniconda 虚拟环境 (`dvlab`)，Python 3.11
- **核心算法**：PyTorch（加载了任务三训练好的 `mnist_cnn.pth` 模型，支持 CUDA 加速）
- **前端交互**：Gradio 库（纯 Python 代码快速生成 Web UI，免去学习前端 HTML/CSS 的成本）
- **图像处理**：PIL## (Pillow) 与 Torchvision

## 三、 整体流程规划
1. 复用任务三的 CNN 网络架构，并加载已保存的 `.pth` 权重文件。
2. 接收 Gradio 画板传入的图像数据。
3. 对图像进行预处理：转换为灰度图 -> 缩放到 28x28 -> 反色处理 -> 转为 Tensor。
4. 将 Tensor 送入模型推理，通过 Softmax 计算概率，取最大值为最终结果。
5. 将结果与置信度返回给前端展示。

## 四、 开发过程遇到的问题及解决办法

1. **输入格式不匹配**：Gradio 新版本画板传回的数据是一个包含图层的字典（dict），直接转 PIL 会报错。**解决**：在代码中加入了 `isinstance(image, dict)` 判断，提取出其中的 `composite`（合成图层）再处理。
2. **黑白颠倒**：Gradio 画板默认是“白底黑字”，而 MNIST 数据集是“黑底白字”。这导致一开始模型识别出来的全是错的。**解决**：查阅了 Pillow 文档，在图像预处理环节引入了 `ImageOps.invert()` 进行颜色反转，准确率瞬间恢复正常。

- **已完成**：Gradio 网页搭建、模型加载、图像预处理（缩放、反色）、实时预测交互。
