## 一、 基础实现与踩坑记录（全连接网络 MLP）

在最初实现手写数字识别时，AI推荐了最基础的多层感知机（MLP）。模型结构为：Flatten (784) -> Linear (256) -> ReLU -> Linear (10)。使用 Adam 优化器与 CrossEntropyLoss，训练 3 个 Epoch，最终测试集准确率为 **97.37%**，Loss 降至 0.0306。（ps.我还在努力理解算法原理）

在此阶段遇到的典型报错与排查过程如下：

1. **NameError: name 'loss_list' is not defined（变量未定义）**
   - **现象**：在训练循环中尝试将 Loss 记录，以便后续绘制曲线时程序崩溃。
   - **排查**：只写了往盒子里放东西（`append`），没有提前准备“盒子”。
   - **解决**：在训练循环开始前，顶格初始化 `loss_list = []` 和 `epoch_list = []`。
2. **NameError: name 'plt' is not defined（缺少库导入）**
   - **现象**：训练跑完后，在最后保存 Loss 曲线图时报错。
   - **排查**：忘记在文件头部导入画图库。
   - **解决**：在代码最上方加上 `import matplotlib.pyplot as plt`。
3. **FileNotFoundError（路径错误）**
   - **现象**：保存模型和图表时，提示找不到 `outputs` 文件夹。
   - **排查**：由于代码在 `src/` 目录下运行，直接写 `outputs/...` 会导致程序在 `src` 内部找。
   - **解决**：将保存路径修改为相对路径 `../outputs/loss_curve.png` 和 `../outputs/mnist_mlp.pth`。

## 一些思考（全连接网络）

- 在与ai交流过程中我了解到全连接网络的识别原理大概是将784个像素进行128次不同方式的加权计算，得到十个分数，以此判断究竟是什么数字。
-
- 因此我有一个疑惑，万一我们数字的书写位置不同，而这个算法是对固定的大致位置进行加权计算识别，这样不就会信息失真了吗，这样不就不能识别出来了吗。
- 我就问他，能不能我们先识别像素为黑色，再以此识别其附近的邻域，这样就可以把数字找出来了，再进行加权计算。数字的大小我们就通过一定邻域内黑色像素与白色像素的占比来判断。
- ai告诉我这有一点像cnn的算法思路，这勾起了我的兴趣，于是我尝试了cnn算法。


## 一些思考2.0（cnn网络）
1. 改成CNN后,正确率提升至98.84%。✿✿ヽ(°▽°)ノ✿
2. 但我依旧不理解，按照我的理解CNN算法的优势应该体现在数字位置不同的时候，但训练库和测试库的数字位置高度一致 ，那么为什么正确率还可以提升呢。
    答：
    1. 局部感受野：全连接把图像展平，破坏了像素的空间相邻关系；而 CNN 通过卷积核滑动，能精准捕捉“横折”、“圆弧”等局部笔画特征。
    2.  参数共享：全连接层参数量巨大，容易陷入特定位置像素的死记硬背；CNN 通过权重共享，逼迫模型学习通用的笔画规律，极大地增强了泛化能力。

3. 数学分析课上，王建军老师简单讲解了一下拓扑，这让我联想到我们能不能用数字的拓扑结构来区分数字？但很快我发现6和9的拓扑结构是一样的。因此我想能不能先用拓扑结构区分，再用cnn算法识别，ai告诉我这个属于混合模型（基于拓扑数据分析的深度学习）

4.  我突发奇想，CNN 识别数字的过程，是不是和人类玩拼图很像？我们不是直接看出整幅画的， 而是先找边缘的碎片（像素突变），再根据边缘的形状找相邻的碎片，最后拼出全貌。

    查阅资料后我发现，这正是 CNN 的运作原理：第一层卷积提取局部边缘（直线/弧线），第二层卷积将边缘组合成中级特征（圆圈/折角），最后的全连接层将高级特征组合成最终的数字分类。

    这种“从局部到整体”的层级结构，完美模拟了人类视觉对关系的识别，比全连接网络把图像拍平粗暴处理要聪明得多。


5. 由此我类比人识别数字的过程，发现即使是近视眼也可以在看见大致轮廓时识别数字，那么计算机是不是也可以在一些细节丢失的情况下完成对数字的识别呢？

    查阅资料后我了解到，CNN 中的“池化层（Pooling）”本质上就是一种降维模糊。为了验证我的猜想，在ai指导下，我使用高斯模糊（GaussianBlur）对测试集进行了处理，并将其输入到训练好的 CNN 中。结果发现，即使图像极度模糊，模型依然保持了 95.36% 的准确率。这证明了 CNN 提取的是“结构特征”而非“像素细节”，完美解释了模型为何具有很强的抗干扰能力。
