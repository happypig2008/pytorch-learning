# 任务二：OKTI 图像压缩与解压
## 1. 项目说明
本项目实现了一个 OKTI（OK Text Image）格式的图像解码器。通过解析文件中的文本字符，还原出完整的 RGB 图像。支持 `p`（完整像素）、`d`（差值）、`r/R`（重复）、`i/I`（历史颜色）六种像素编码方式，并使用 Pillow 库将像素绘制为可视化的图片。

## 2. 环境与运行方式
- **环境**：Python 3.10, Pillow (PIL)
- **依赖安装**：`pip install pillow`
- **运行方式**：
  - 带参数运行：`python src/task2_okti_decoder.py <文件名.okti>`
  - 无参数运行：直接运行程序，根据提示输入文件名。
  - 智能路径识别：如果只输入文件名（如 `small.okti`），程序会自动在 `tests/valid/` 或 `tests/invalid/` 中查找；如果输入完整绝对路径（如 `C:/Users/...`），则直接读取用户指定的外部文件。

## 3. 项目结构

task2_okti_decoder/
├── src/               # 源代码

└── docs/              # 开发笔记与AI使用日志

## 4.核心实现思路
-  p 类型：解析 6 位十六进制，转换为 RGB 三原色。
- d 类型：解析 3 位十六进制，减去偏置 8，与上一个像素相加得出新颜色。
-  r/R 类型：按指定次数复制上一个像素。
-  i/I 类型：维护一个最多 256 个颜色的历史列表，按索引取值。
-  图像绘制：利用 pixel_count % w 和 pixel_count // w 算出坐标，使用 Pillow 的 putpixel 逐像素绘制。


## 5.测试异常与处理
- 程序能够妥善处理四种异常（已在 tests/invalid 中提供测试文件）：
1. 文件不存在。
2. 首行不是 "okti"。
3. 宽高小于等于 0。
4. 遇到非法像素类型（会打印行号和错误内容，并安全退出）。

## 6.数据缩减量说明

以一个纯色像素为例：完整 RGB 使用 pff0000 占 7 个字符；使用差值 d000 只占 4 个字符。OKTI 格式正是通过差值、重复、索引机制，实现了文本层面的数据压缩。
