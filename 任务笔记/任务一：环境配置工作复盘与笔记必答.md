# 操作步骤及原理分析

##  安装 Miniconda（大管家）


 操作：去 Anaconda 官网下载体积较小的 Miniconda 并安装。
 原理：Python 本身只是一门语言。Miniconda 是一个包管理器和环境管理器, 它能帮我们轻松下载、管理代码运行所需的工具库（比如 PyTorch）。
 关键点：安装时绝对不勾选“Add to PATH”，避免搞乱电脑系统自带的 Python。
 ***
##  创建虚拟环境（建独立房间）

· 操作：在命令行输入 conda create -n pytorch_env python=3.10 -y。
· 原理：为了避免 A 项目和 B 项目因为需要的库版本不同而打架，需要专门建了一个叫 pytorch_env 的隔离房间，里面只装 Python 3.10。以后所有操作都在这个房间里，互不干扰

***
## 安装 PyTorch（买核心家具）

· 操作：在 pytorch_env 房间内执行 pip install torch torchvision torchaudio。
· 原理：将 PyTorch 深度学习框架（CPU 版）及其依赖库下载到刚才建的隔离房间中。
· 关键点：因为我的电脑是 AMD 显卡，不能用 NVIDIA 显卡独有的 CUDA 加速，所以只能装 CPU 版。

***
## 配置 PyCharm（打通工作台与房间）

· 操作：在 PyCharm 新建项目时，手动指定解释器路径为 C:\Users\Administrator\miniconda3\envs\pytorch_env\python.exe
· 原理：PyCharm 只是写代码的“工作台”，它本身不懂 Python。需要把之前建好的“房间”里的 Python 解释器指给它，它才能调用咱们装好的 PyTorch。
***
## Git 与 GitHub（存档与云备份）


· 操作：安装 Git，配置用户名和邮箱，在 GitHub 建新仓库，然后通过 PyCharm 进行 Commit（本地存档）和 Push（上传云端）。
· 原理：Git 负责记录代码的每一次修改（像游戏的存档点）；GitHub 是云端的网盘。

# 问题反思


## 如何判断自己应该安装哪个版本的 PyTorch 的？

· 判断依据：通过查看电脑硬件配置来判断。
· 排查思路：
  1. 我按下了 Ctrl + Shift + Esc 打开任务管理器，点击“性能”选项卡，查看了我的显卡（GPU）信息。
  2. 我的电脑显卡是 AMD Radeon 集成显卡。
  3. 深度学习中的 GPU 加速依赖于 NVIDIA（英伟达）的 CUDA 技术。因为我的电脑没有 NVIDIA 独立显卡，所以我判断我不能安装 CUDA 版，必须安装 CPU 版的 PyTorch。
  4. 验证：安装完成后，我在 Python 中运行了 torch.cuda.is_available()，返回了 False，这进一步验证了我的判断，但我用 CPU 学习基础概念完全足够。

## 报错

### 一 镜像站拒绝访问

· 现象：误以为需要外国手机号，想用清华、中科大镜像站下载 Anaconda 时，网页显示红字“拒绝访问”。
· 排查：判断为校园网防火墙对开源镜像站有限制。
· 解决：放弃国内镜像站，改去 Anaconda 官网，选择体积更小的 Miniconda 下载，成功避开网络拦截。并且发现不需要。

### 二   服务条款未接受错误

· 现象：在命令行输入创建环境命令时，报错提示“Terms of Service have not been accepted”。
· 解决：直接在报错提示中找到了官方给出的解决方法，在命令行依次执行了三行 conda tos accept ... 命令，同意条款后恢复正常。

### 三 PyCharm 创建项目时按钮点不动


· 现象：在 PyCharm 中配置环境时，选择 Conda 类型，路径指向 python.exe，下方警告“所选工具不是 conda”，创建按钮被锁定。
· 解决：将“解释器类型”从 Conda 改为 Python，并手动浏览到正确路径 ...\envs\pytorch_env\python.exe，警告消失，项目成功创建。

### 四 Git 配置身份命令报错 error: no action specified


· 现象：在终端粘贴 Git 配置命令时，由于操作失误，把名字和邮箱粘贴到了同一行。
· 解决：放弃复制粘贴，手动分两行分别输入命令 git config --global user.name "happypig2008" 和 git config --global user.email "邮箱"，成功解决问题。
